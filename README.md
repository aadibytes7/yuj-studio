# YUJ Studio V2.4 — GitHub Pages package

## Deploy
1. Create a **public** GitHub repository named `yuj-studio`.
2. Upload all files and folders from this package (not the ZIP itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Wait a minute or two. The site URL will be `https://YOUR-USERNAME.github.io/yuj-studio/`.

## Important
The original individual SVG artwork files were not included in the supplied uploads. The `assets/sample-library/` files are stand-in visuals preserving expected paths; replace them with original SVGs for the intended artwork. Diffusion generation requires a separately running endpoint; GitHub Pages hosts only the static frontend.
